Privacy Policy — JobSeeker Chrome Extension

Last updated: 2026-05-31

What data we handle

The JobSeeker extension stores two items locally in your browser using Chrome's storage API (chrome.storage.local): your resume text and your Anthropic API key. Neither item is transmitted to any server controlled by the developer.

What Anthropic receives

When you trigger analysis, your resume text and the LinkedIn job description text are sent directly from your browser to Anthropic's API using your own API key. This is subject to Anthropic's privacy policy.

No analytics or tracking

The extension collects no analytics, telemetry, or usage data. No data is shared with third parties beyond Anthropic's API as described above.

Data deletion

To delete all stored data, open the extension's Settings page and clear the resume and API key fields, or remove the extension from Chrome.
